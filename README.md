Set de monitoreo en Grafana — Excavadoras EX3600

Monitoreo de condición basado en telemetría para una flota de excavadoras hidráulicas mineras EX3600. El proyecto define 28 sets de monitoreo sobre 6 sistemas del equipo, los implementa como dashboards en Grafana y los convierte en informes accionables para el área de Confiabilidad, que genera las órdenes de trabajo.
